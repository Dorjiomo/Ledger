GitHub sync

Keeps a copy of your records in a private GitHub repository, so you can restore them on any phone. Use a separate repo for data, never your public website repo.
How to set it up
  1. On GitHub, create a new private repository, for example ledger-data, and tick “Add a README”.
  2. Go to Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  3. Under Repository access choose “Only select repositories” and pick ledger-data. Under Permissions set Contents to “Read and write”.
  4. Copy the token, paste it above with your repository name, then tap Save to GitHub.
The token stays on this phone only. It is not part of backups and never goes into the repo. If two phones save at once, the last save wins.

Backup

Your data lives in this browser on this phone. Unless you turn on GitHub sync it is never uploaded. Clearing Chrome data deletes it, so keep a backup.
